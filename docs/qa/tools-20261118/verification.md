# Проверка обновления инструментов — 18.11.2026

## Выполнено

- Формы с обязательными полями, раскрываемыми подробностями, выбором акций и схем платежей.
- Субсидия от окончательного кредита, компенсация по настройке проекта, ручной ПВ, порог 71%, округление только отображения.
- Этапы в рублях/по датам; действующие ежемесячные рассрочки ДНК сохраняют промежуточные этапы.
- ИИ проверяет числовые последовательности и единицы; предложения проходят предпросмотр. Одновременно видно одно окно.
- Спецквартиры остаются в калькуляторах с предупреждением. «Стоимость денег» берётся из инструмента ЧПВ.
- Дисклеймер на каждой странице PDF.
- SQLite вместо общего Google-каталога; банковский импорт остаётся отдельным. Частные записи исключены из публичного снимка.

## Проверки

- Node: 40 проверок — успешно.
- Python: 109 проверок — успешно. Для полного набора использовано окружение с PyMySQL, нужным тесту Macro.
- Браузер: пять страниц, две темы, ширины 1280/390 px; ошибок JS и горизонтального переполнения нет. Новые формы дополнительно проверены на 320 px.
- Создание всех расчётных типов, смена схемы, обязательные поля, копирование частного инструмента в публичный, сохранение совместимости банковской карточки без отключения импорта.
- ИИ → редактирование → отмена / крестик / сохранение: одно окно и один запрос при сохранении. Тестовые обращения к API заменены заглушками; платных ИИ-вызовов не было.
- PDF: длинные расчёты на 7–9 страницах, обе ориентации; все проверочные строки сохранены, дисклеймер не перекрывает расчёт.
- ЧПВ: возврат к проекту восстанавливает цену квартиры. Автоподбор не вставляет ДДУ с отрицательным финансированием ПВ.
- Перенос: 164 общие и 2 закрытые записи, после банковского обновления 165 общих и 2 закрытые. Исходные записи сохранены отдельно, восстановление SQLite проверено.

## Ограничения источников

- Справочник субсидий ДА возвращает ошибку `G34: #VALUE!`; для двух очередей ДА сохранены последние проверенные ставки. ДНК обновляется.
- Свободный текст прежних сочетаний не преобразован в произвольные галочки. Текст сохранён и показан в форме; совместимые акции выбирает владелец. Только явно заданный числовой параметр акции меняет цену.
- Резервные файлы в локальной папке и папке синхронизации Google Диска проверены восстановлением. Загрузку второй копии в облако независимо подтвердить не удалось (API 403).
