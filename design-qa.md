## Общие компоненты и движение · 19 ноября 2026

Пять страниц используют HTML, CSS и обычный JavaScript. Движение задают CSS-переходы и Web Animations API. У сайта нет сборщика, менеджера пакетов приложения и зависимости от React. Проектный навык Animate UI установлен в `.agents/skills/animate-ui`, версия источника закреплена в `skills-lock.json`. Для списка применены правила [Animate UI Select](https://animate-ui.com/docs/primitives/base-ui/select) с сохранением стандартного HTML-поля. Общие длительности и кривые для CSS и JavaScript находятся в начале `assets/themes.css`.

- **Выбор значения.** Хранить значение в одном `select`. В поддерживающих браузерах оформлять его родное меню через `::picker(select)`. Браузер отвечает за фокус, стрелки, Escape, прокрутку и выбор стороны раскрытия. При отсутствии поддержки остаётся системное меню. Выбранная строка отмечена цветом и галочкой. Длинное название переносится в раскрытом списке.
- **Ввод номера квартиры.** У редактируемого поля показывать варианты своего проекта. При навигации по подсказкам фокус остаётся в поле. Enter выбирает строку, Escape возвращает к вводу. Переход к соседнему списку квартир закрывает подсказки. При точном совпадении цену и расчёт обновлять сразу.
- **Действия и редактирование.** Кнопка открывает один слой. Escape сначала закрывает список, затем ближайший раскрытый раздел, затем форму. Фокус возвращается к управляющему элементу. При закрытии мышью неактивный слой может закончить визуальный переход, пока нижний уровень уже готов к работе.
- **Кнопки, вкладки и результат.** При повторном нажатии учитывать текущее визуальное состояние. Начинать движение подсветки в момент клика и продолжать его с той же позиции на новой странице. Заголовок и форму выводить сразу после получения HTML и стилей. Загрузка каталога и резервных данных не должна удерживать на экране предыдущий раздел. Форму и цифры оставлять на месте. Обновление расчёта выполнять в обработчике выбора, до завершения визуального отклика. При наборе суммы сохранять положение курсора и текста.
- **Проверка.** Смотреть промежуточные кадры открытия, выхода и быстрого повторного нажатия. Проверять две темы, узкий экран, клавиатуру и уменьшенное движение. Для сравнения расчётов брать один снимок данных, одну дату сделки, одинаковую квартиру и параметры по каждой из четырёх вкладок.
