# Калькуляторы ипотеки и рассрочки «Свобода мысли»

Четыре страницы без сервера: `index.html` — ипотека, `rassrochka.html` — рассрочка, `chpv.html` — ЧПВ, `transh.html` — траншевая ипотека. Считают в браузере, сохраняют расчёт в PDF.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `assets/data.js` | Рассрочки и резервный снимок ипотеки; транши — в transh.js, ЧПВ — в chpv.js |
| `assets/mortgage.json`, `assets/mortgage-loader.js` | Автоматически проверяемые ставки и комиссии ДА/ДНК и загрузка на странице ипотеки |
| `assets/engine.js` | Расчёты, без обращения к странице |
| `assets/common.js` | Поля ввода и сохранение в PDF |
| `assets/ipoteka.js`, `assets/rassrochka.js` | Сами страницы |
| `assets/style.css` | Оформление |
| `tests/engine.test.mjs` | Проверки расчётов |

## Как обновить условия

Ипотечные программы ДА/ДНК автоматически поступают из отдельных справочников — см. ниже. Условия рассрочек, траншей и ЧПВ пока обновляются вручную; в `assets/data.js` поле `updated` относится к ручной сверке и резервной ипотечной копии. После ручной правки запустить проверки и отправить изменения в `main` — сайт обновится через минуту-две.

```bash
node tests/engine.test.mjs
```

Проверки на конкретные суммы завязаны на цифры снимка. Когда условия меняются, эти суммы нужно пересчитать, а не подгонять.

## Как посмотреть на своём компьютере

```bash
python3 -m http.server 8792
```

Затем открыть http://localhost:8792.


## Автообновление квартир

`automation/sync_macro.py` раз в три часа через Macro BI считывает свободные квартиры трёх домов ДДУ (без ПИФ) и обновляет `assets/macro-flats.json` на GitHub. Работает на этом Mac через launchd, пока Mac включён и есть интернет, доступ к Macro BI и GitHub. Исходная дата — время сервера Macro. Если выгрузка BI старше 48 часов, данные повреждены, число квартир упало более чем вдвое или GitHub изменился во время отправки, старый снимок остаётся на сайте.

Доступ к Macro — только чтение, настройки берутся из `~/code/agent-sales-bi/.env`, локальный переходник — `127.0.0.1:3307`. Пароли в GitHub не передаются. На опубликованном сайте, как и прежде, список и цены видны всем. Это задание не изменяет программы: для ипотечных справочников есть отдельная синхронизация ниже.

Проверка без публикации: `~/code/agent-sales-bi/.venv/bin/python automation/sync_macro.py --dry-run`. Состояние: `launchctl list | grep ru.svobodamysli.ipoteka-macro`; журнал: `~/Library/Logs/ipoteka-macro.log`.


## Расчёт ЧПВ

`chpv.html` повторяет формулы активного листа «Расчёт ЧПВ»: по очередям ДА, с возможностью ввести цену ДДУ вручную или подобрать её до порога вердикта таблицы (округление вверх до 1 000 ₽). Ставки и лимиты справочные. Если есть сверхлимит, как в таблице, платёж рассчитывается по 14% на весь кредит; его нужно подтверждать с брокером. Активная таблица не проверяет максимальную долю финансирования ПВ; при доле свыше 50% показано предупреждение. Для ДНК условия ещё не согласованы.

Проверка: `node tests/chpv.test.mjs`, `node tests/flats.test.mjs`, `node tests/engine.test.mjs`.


## Траншевая ипотека

Три схемы Сбербанка для ДНК-2 взяты из «ДНК-2. Инструменты продаж»: 19,2%, первый транш 20%, 10% или 1% с минимумом 100 000 ₽, второй 20%, последний — остаток. К базовой скидке автоматически добавляются 2% для сделок до 30.11.2026 включительно; скидку можно изменить. Последний транш показывается в мае 2029 года без выдумывания точного дня; его при необходимости вводят вручную. Для ДА Евгений подтвердил первый транш 100 000 ₽, второй — остаток кредита, и 06.11 выбрал предварительный расчёт по ориентиру 1 500 ₽. По умолчанию этот ориентир на 30 лет задаёт оценочную ставку (обратный расчёт аннуитета). Ею считаются оба этапа; при смене срока меняется платёж, а оценочная ставка сохраняется. Это явно помечено на странице и в PDF как оценка, не банковское предложение. Дата второго транша подставляется из подтверждённых подсказок: ДА1 — 20.03.2027, ДА2 — 20.09.2028; её можно изменить. Название банка необязательно. Для точного расчёта есть отдельный вариант «По точной ставке банка».

По указанию Евгения предварительный аннуитет каждого этапа считается от всей суммы, выданной на тот момент, на исходный срок кредита: промежуточное погашение и точная дневная схема банка не моделируются. Даты, ставка, срок и суммы проверяются на корректность. Проверка: `node tests/transh.test.mjs`.


## Полная сверка 06.11.2026

Справочники ДА и ДНК прочитаны заново: 30 и 23 ипотечные программы. Ставки, комиссии, сроки и лимиты перенесены из соответствующих справочников. Ипотечная комиссия по-прежнему считается от прайса минус взнос; платёж — от цены ДДУ минус взнос. Евгений подтвердил 06.11.2026: платёж считать от фактического кредита (ДДУ минус взнос), сохранив это отличие от таблицы, где платёж считается от прайса. Точная цена за наличные из Macro сохраняется без потери на округлении процента скидки. Если цены за наличные нет, скидка требует ручного ввода.

Рассрочки: четыре варианта для каждой очереди ДА (от 30%, ежемесячная, для будущих родителей на 3/6 месяцев) и пять для ДНК. Для ДА-2 программа от 30% длится 24 месяца от сделки; 05.07.2028 в источнике — пример. В этой программе взнос и его доля считаются от прайса, как в листе скидок, и это явно подписано. Дополнительная скидка ДА применяется последовательно. Для ДНК учтены промежуточные 10%/5%, фиксированные даты, вариант ПВ 70%, стартовые 2% до 30.11.2026; программа без ПВ не принимает дополнительные скидки.

Равные платежи округлены до рублей, разница попадает в последний платёж к конечной дате. Ежемесячные платежи считаются со следующего месяца до месяца погашения; точный банковский/договорный график не моделируется. Просроченный график не рассчитывается. При истёкшем сроке действия условий ДА показывается предупреждение. ДА 50/50 не подключена из-за противоречивых сроков в источнике (погашение 30.09.2026, предложение до 20.03.2027). Нежилые помещения и ПИФ исключены из задачи.

ЧПВ сверено с активным листом. Отрицательное финансирование блокируется. Лимит финансирования 50% и ставка комбо 14% на весь кредит остаются ограничениями исходной таблицы, явно отмеченными в результате. Для ДНК параметров ЧПВ нет, подстановка условий ДА запрещена. В траншах ДНК остаётся противоречие мая 2029 и ввода в IV квартале 2029, показанное в интерфейсе.

Проверки: `node tests/engine.test.mjs`, `node tests/audit.test.mjs`, `node tests/chpv.test.mjs`, `node tests/transh.test.mjs`, `node tests/flats.test.mjs`. В расширенном тесте — независимое погашение аннуитета, баланс графиков, даты и денежный ввод. В браузере проверены четыре страницы, ширина 390 px, выбор квартиры, PDF ипотеки, рассрочки (пять отдельных страниц) и траншей. Macro `--dry-run` завершился: опубликованный снимок совпадает с BI.

Переключение проектов (исправление по записи экрана 06.11): ручная цена без выбранной квартиры переносится в новый проект для сравнения. При возврате восстанавливаются номер, цена и скидка этого проекта; квартира из другого дома не подставляется. Состояние хранится только на время открытой страницы. Нажатие на уже активный проект не сбрасывает поля. Проверка — `tests/flats.test.mjs` и повтор действий из записи в браузере.


## Автообновление ставок и комиссий — 06.11.2026

По новому поручению Евгения прежний ручной режим для ипотеки заменён автоматическим. `automation/sync_mortgage.py` читает «Справочник субсидий ДА» и «Справочник субсидий ДНК» и публикует только `assets/mortgage.json`. Вместе со ставками и комиссиями переносит банк, условие по детям, срок и лимит. Минимальный взнос остаётся утверждённым: ДА 20,1%, ДНК 20%. Рассрочки, транши, ЧПВ и Macro не меняет.

Работает на этом Mac каждые три часа (`ru.svobodamysli.ipoteka-mortgage`), при включённом Mac, интернете и действующем доступе `gh`. ID таблицы и листов находятся только в `~/.config/ipoteka-calc/sheets.json`, вне открытого репозитория. Используется уже разрешённое чтение таблицы по ссылке: доступы Google не меняются, пароли не нужны. Если доступ к источнику закроют, синхронизация остановится, старый снимок сохранится.

Сырые CSV-ячейки проверяются на ошибки, затем сравниваются с листом по имени и значениями исходной точности Google. Формат колонок, оба проекта, числовые диапазоны, комиссии, лимиты и дубли обязательны; если один лист сломан, ни один не публикуется. Падение количества программ более чем вдвое для любого проекта останавливает обновление. GitHub Contents API принимает текущий SHA файла: параллельные правки не затираются. Успешная проверка обновляет время снимка даже при тех же ставках.

При открытии страницы ипотеки загружается этот JSON без браузерного кэша. Внизу видно время проверки по Екатеринбургу. Через 12 часов без успешной синхронизации появляется предупреждение. Если JSON недоступен/повреждён, используется встроенная проверенная копия из `data.js` с явным предупреждением и её датой. Открытую страницу после обновления нужно перезагрузить. Формула платежа остаётся от фактического кредита: цена ДДУ минус взнос.

Команды:

```bash
python3 automation/sync_mortgage.py --dry-run
python3 automation/install_mortgage_job.py
launchctl print gui/$(id -u)/ru.svobodamysli.ipoteka-mortgage
```

Журнал: `~/Library/Logs/ipoteka-mortgage.log`. Восстановление на другом Mac: клонировать репозиторий, восстановить локальный JSON из закрытой памяти среды «Евгений Гусев» (заметка `ipoteka-auto-rates`), подключить `gh`, выполнить проверку без публикации и установку задания. Нужны Python 3.9+, curl и gh; дополнительных Python-пакетов нет. Для проверки исходников: `python3 tests/sync_mortgage_test.py`, `node tests/mortgage-loader.test.mjs` и существующие тесты расчётов.

## Рассрочка: единый вид с ипотекой

Условия покупки и настройки выбранной программы слева, её стоимость и график справа, все варианты в таблице снизу. Нажатие строки или названия программы переключает расчёт. Выбор программы, взноса и периодичности сохраняется для каждого проекта до закрытия страницы. На телефоне блоки идут последовательно, таблица вариантов становится компактными строками. PDF и печать относятся к выбранному расчёту; PDF — один лист A4. Формулы, даты и предупреждения из полной сверки сохранены.


Проверка траншей ДА после уточнения: квартира 10 млн ₽, без скидки, ПВ 20,1% (2,01 млн), кредит 7,99 млн. Первый транш 100 тыс., второй 7,89 млн; предварительные платежи на 30 лет — 1 500 ₽ и 119 850 ₽. Восстановленная ставка хранится с полной точностью, в интерфейсе округляется до сотых; она не объявляется текущей ставкой какого-либо банка. Регрессии — в `tests/transh.test.mjs`; выбор квартиры, обе очереди и переход к точной ставке проверяются в браузере.
