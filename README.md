# Калькулятор — переадресация на защищённый сервер

Эта ветка содержит только переадресацию; вход и все данные доступны на сервере приложения.

Адрес приложения: https://academic-towering-horizon.ihchost.rocks/static/app/calculator/

Публичных JS/CSS-сборок, квартир и каталога инструментов в текущем дереве нет. Пути legacy/ ведут в защищённую старую версию на том же сервере. История Git и ветка main не изменены; прежние опубликованные данные остаются в истории. Фоновая публикация снимков заблокирована маркером release.json.
