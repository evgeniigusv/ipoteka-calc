# Калькуляторы ипотеки и рассрочки «Свобода мысли»

Две страницы без сервера: `index.html` — ипотека, `rassrochka.html` — рассрочка. Считают в браузере, сохраняют расчёт в PDF.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `assets/data.js` | Программы, ставки, условия рассрочек. Единственный файл, который меняется при обновлении условий |
| `assets/engine.js` | Расчёты, без обращения к странице |
| `assets/common.js` | Поля ввода и сохранение в PDF |
| `assets/ipoteka.js`, `assets/rassrochka.js` | Сами страницы |
| `assets/style.css` | Оформление |
| `tests/engine.test.mjs` | Проверки расчётов |

## Как обновить условия

Страницы таблиц не читают: условия лежат снимком в `assets/data.js`, дата снимка — в поле `updated`.
После правки запустить проверки и отправить изменения в ветку `main` — сайт обновится сам через минуту-две.

```bash
node tests/engine.test.mjs
```

Проверки на конкретные суммы завязаны на цифры снимка. Когда условия меняются, эти суммы нужно пересчитать, а не подгонять.

## Как посмотреть на своём компьютере

```bash
python3 -m http.server 8792
```

Затем открыть http://localhost:8792.
