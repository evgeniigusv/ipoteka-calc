# Калькуляторы «Свобода мысли»

GitHub Pages: ипотека, рассрочка, ЧПВ, траншевая ипотека и единая вкладка **Инструменты**. Квартиры и цены — из Macro, условия — из Google. Вкладка инструментов сравнивает ДА1, ДА2 и ДНК-2, поддерживает поиск и PDF выбранных проектов/результатов поиска.

## Источник условий

Основной источник — отдельный лист **«Инструменты калькулятора»** в книге инструментов продаж. В него перенесены программы из справочников субсидий, инструментов ДА и ДНК. Прежние листы остаются для сверки; автоматическое чтение калькулятора идёт из общего листа. Его ID и ссылка находятся только во внешней конфигурации владельца и GitHub Secret `TOOLS_SOURCE`.

`assets/tools.json` — проверенная публичная копия. `tools-model.js` задаёт общую схему для импорта, редактора и всех калькуляторов. `tools-loader.js` загружает снимок без кэша после старых загрузчиков. При сбое используются прежние проверенные данные, страница инструментов явно сообщает о недоступности. Открытый калькулятор нужно перезагрузить после изменения справочника.

GitHub Actions: полный справочник — каждый понедельник в 06:00 Екатеринбурга (01:00 UTC); ипотечный раздел, включая ставки и комиссии, — каждые три часа. GitHub может запускать плановые задачи с задержкой. Сохранение владельцем публикует все разделы сразу; сборка Pages обычно занимает 1–2 минуты. Квартиры обновляются прежним отдельным заданием Macro.

## Личный редактор

Публичный сайт не содержит ключей или API записи. Кнопка «Редактировать» ведёт на `http://127.0.0.1:8795/tools.html` — редактор на Mac владельца. Он работает только на loopback, использует существующее подключение Google и `gh`. У коллег личный сервер отсутствует: им доступны просмотр и PDF.

- Быстрая ставка — нажать цифру в ячейке, подтвердить галочкой.
- Полные параметры и сочетание акций — карандаш нужного проекта.
- Новая программа — «Добавить инструмент». Механика определяет, в какой калькулятор она попадёт. Информационный инструмент отображается только в каталоге.
- Для отсутствующего проекта — «Добавить условия», затем проверить предложенные параметры.
- «Применить к таблице» готовит правку; **«Сохранить в Google»** записывает её в источник и публикует снимок. До этого PDF недоступен, чтобы черновик не ушёл партнёрам.
- Если Google изменился с момента чтения, запись остановится: перечитать и повторить правку. Проверка версии не является транзакцией Google; не редактируйте одну строку одновременно в двух окнах.
- Если Google принял запись, а GitHub недоступен, видна отдельная кнопка повторной публикации. Повтор не создаёт новые строки.

Кредитные параметры проверяются до записи. Нельзя удалить последнюю активную ипотеку/рассрочку проекта, задать отрицательные суммы, неверные даты или этапы сверх 100%. Отключение программы — снять «Активен»; данные остаются в источнике и истории Git. Дата окончания в исходных условиях не продлевается автоматически.

Запуск: `python3 automation/tools_editor.py`. Автозапуск macOS: `python3 automation/install_tools_editor.py`. Журнал: `~/Library/Logs/ipoteka-tools-editor.log`. Конфигурация: `~/.config/ipoteka-calc/tools.json`, права 0600; поля `spreadsheet_id`, `gid`, `sheet_name`, `credentials`, `repo`. OAuth-файл находится вне репозитория. При истечении подключения Google его нужно переподключить у владельца.

## API для робота на Mac

`GET /api/session` устанавливает HttpOnly/SameSite cookie и возвращает CSRF. `GET /api/tools` возвращает `version`, `checked_at`, `revision`, `records`. `POST /api/tools` принимает `{revision, changes: [полные записи]}`; нужны сессионная cookie, заголовки `Origin: http://127.0.0.1:8795` и `X-CSRF-Token`. `POST /api/publish` с `{}` повторяет публикацию текущего Google-снимка. Изменять `group` следует только при сознательном объединении строк разных проектов.

Поля записи: `id`, `group`, `category`, `name`, `project`, `kind`, `description`, `combination`, `mode`, `params`, `enabled`. Все разрешённые поля и диапазоны описаны в `assets/tools-model.js`. Проценты в параметрах — доли (0.06 = 6%), деньги — целые рубли. Новая запись требует уникального ID. Запись ограничена конкретным настроенным листом; никаких OAuth-ключей в запросах браузера нет.

## Формулы и ограничения

- Ипотека: платёж от фактического кредита, **цена ДДУ минус ПВ**. Комиссия банку — от прайса минус ПВ, как в исходной таблице. Цена выбранной квартиры из Macro сохраняет своё значение.
- Рассрочка: равные платежи, ежемесячная сумма с остатком, отсрочка или этапы; последовательное либо суммарное применение дополнительной скидки. У условий с индивидуальным согласованием дополнительная скидка автоматически не применяется.
- Транши: платежи от накопленной выданной суммы на первоначально выбранный срок. ДА — 100 000 ₽ и остаток, предварительно по ориентиру 1 500 ₽ на 30 лет; также можно ввести точную ставку. ДНК — три транша. Расчёт не заменяет банковский график с погашением основного долга.
- ЧПВ: сохраняет формулы исходного листа, включая расчёт сверхлимита по отдельной ставке. Условия ДНК не добавлены без источника; при добавлении подтверждённой программы через каталог проект появится в калькуляторе.
- Партнёрский PDF не выводит комиссию банку. Все проекты дают объёмный справочник; для короткого файла выберите проект или отфильтруйте нужный инструмент.

## Macro и восстановление

`automation/sync_macro.py` раз в три часа обновляет `assets/macro-flats.json` через Macro BI на Mac. Только свободные квартиры трёх домов ДДУ, без ПИФ. Доступ и конфигурация хранятся в защищённой среде Macro BI; этот редактор их не меняет. Задание `ru.svobodamysli.ipoteka-macro`. Журнал `~/Library/Logs/ipoteka-macro.log`.

Сайт и история снимков находятся в GitHub. Для восстановления сайта достаточно клонировать репозиторий и включить Pages для `main`. Google остаётся независимым основным хранилищем. Для восстановления редактора на другом Mac нужны сохранённая внешняя конфигурация, подключение Google, Node.js, Python 3.9+, curl и авторизованный `gh`; затем установить автозапуск. OAuth и настройки источников восстанавливаются из закрытой резервной копии владельца, не из публичного Git.

Проверка без публикации: `python3 automation/sync_tools.py --dry-run`. Для GitHub чтения достаточно `TOOLS_SOURCE` с `spreadsheet_id`, `gid`, `sheet_name`: OAuth в GitHub не передаётся. Таблица должна сохранять уже существующий доступ чтения по ссылке. Если он закрыт, старый снимок остаётся на сайте.

## Проверки

`node tests/tools.test.mjs`, `python3 tests/tools_source_test.py`, остальные `tests/*.test.mjs` и `tests/*_test.py`. Фикстура `tests/fixtures/tools-initial.json` фиксирует перенос исходных формул; текущие условия могут меняться в Google независимо от неё. Локальный просмотр без редактирования: `python3 -m http.server 8796`.
