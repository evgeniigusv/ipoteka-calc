Основной сайт: https://evgeniigusv.github.io/ipoteka-calc/

Прежняя версия: https://evgeniigusv.github.io/ipoteka-calc/legacy/

Эта ветка содержит только публичную сборку. Исходники React находятся в закрытом evgeniigusv/ipoteka-calc-react. Ветка main сохраняет прежний калькулятор. Для отката переключите Settings → Pages → Branch на main, папка /.
